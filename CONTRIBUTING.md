# Contributing to FeeForge 🤝

Thanks for taking the time to contribute! FeeForge is a zero-build, vanilla HTML/CSS/JS project, so getting started takes seconds.

## Getting started
1. Fork the repo and clone your fork
2. Open `index.html` in a browser (or run `npx serve .`)
3. Create a branch: `git checkout -b feat/my-idea`
4. Make your change, test **Generate → Print → Download PDF**
5. Commit using [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`…)
6. Push and open a Pull Request

## Guidelines
- Keep it dependency-light (no build step required)
- Match the existing code style (`.editorconfig`)
- One focused change per PR
- Be kind — see the [Code of Conduct](CODE_OF_CONDUCT.md)
