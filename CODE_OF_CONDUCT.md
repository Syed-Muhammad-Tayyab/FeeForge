# Code of Conduct

## Our pledge
We pledge to make participation in FeeForge a harassment-free experience for everyone, regardless of age, background, identity, experience level, nationality, appearance, religion, or orientation.

## Our standards
**Do:** be respectful, welcome newcomers, give and accept constructive feedback gracefully, focus on what is best for the community.

**Don't:** use sexualised language, troll, insult, harass, or publish others' private information.

## Enforcement
Maintainers may remove, edit, or reject comments, commits, issues and other contributions that violate this Code of Conduct. Report unacceptable behaviour by opening a private security advisory or contacting the maintainer via GitHub: [@Syed-Muhammad-Tayyab](https://github.com/Syed-Muhammad-Tayyab).

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
